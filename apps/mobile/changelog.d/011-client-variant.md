Added an opt-in Feitu Android client variant with its own package ID, app name and link scheme. It uses `https://api.feitu.net.cn` for email sign-in. Its Firebase file is optional and must match the Feitu package; Android push stays disabled until that file is configured. Existing `openbot://` Mobile Connect QR links still work when scanned in the app. Android registers only `feitu-openbot`, so an OS-open `openbot://` link does not launch Feitu; a self-hosted link producer needs a product-aware change to emit the Feitu scheme.
